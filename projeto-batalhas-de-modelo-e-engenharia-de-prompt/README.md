# 📌 Sobre o Projeto

Este projeto teve como objetivo comparar diferentes modelos de Inteligência Artificial na criação de um mesmo site utilizando exatamente o mesmo prompt estruturado em XML.

A proposta consistia em gerar uma página HTML Single Page sobre:
# 🍰 Receita de Bolos de Chocolate

O experimento foi realizado utilizando diversas IAs generativas para avaliar:
- qualidade do código;
- compreensão do prompt;
- criatividade;
- precisão visual;
- estrutura HTML;
- quantidade de tokens;
- erros de sintaxe;
- eficiência geral.

---

# 🧠 Objetivos do Projeto

- Comparar diferentes modelos de IA;
- Avaliar interpretação de prompts estruturados;
- Testar engenharia de prompt em XML;
- Analisar qualidade de código HTML/CSS gerado;
- Identificar qual IA produz melhores resultados em prototipagem web.

---

# 🤖 Modelos de IA Testados

Durante o projeto, o mesmo prompt foi utilizado nas seguintes IAs:

- ChatGPT
- Gemini
- Claude
- Qwen
- DeepSeek
- Grok
- Maritaca AI

# 📄 Estrutura do Prompt Utilizado

O prompt foi desenvolvido em XML estruturado para padronizar a entrada entre todos os modelos.

## 📌 Objetivo do Prompt
Gerar:
- uma página HTML5 única;
- CSS3 interno;
- layout responsivo;
- design minimalista;
- tema de bolo de chocolate.

## ⚙️ Funcionalidades Obrigatórias

# 🧪 Metodologia do Experimento

Todos os modelos receberam:
- exatamente o mesmo prompt;
- mesma estrutura XML;
- mesmos requisitos técnicos;
- mesmo objetivo final.

Posteriormente foram analisados:
- criatividade;
- precisão;

- qualidade visual;
- organização do código;
- uso de tokens.

---

# 🏆 Melhor Modelo do Experimento

## 🥇 Claude

O Claude apresentou:
- melhor interpretação do XML;
- design mais sofisticado;
- maior criatividade;
- animações e efeitos;
- excelente estrutura HTML;
- organização impecável;
- ausência de bugs.

Apesar do maior consumo de tokens, foi o modelo que entregou o resultado mais profissional.

---

# 📈 Análises Obtidas

## 🔍 Diferença Entre os Modelos
O projeto demonstrou que diferentes IAs:
- interpretam prompts de maneiras distintas;
- possuem níveis diferentes de criatividade;
- variam drasticamente na qualidade do código gerado.

---

# 💡 Principais Descobertas

Foi possível observar que:
- prompts estruturados melhoram resultados;
- XML ajuda na organização da IA;
- modelos maiores tendem a gerar resultados mais completos;
- maior quantidade de tokens geralmente resulta em projetos mais refinados.
