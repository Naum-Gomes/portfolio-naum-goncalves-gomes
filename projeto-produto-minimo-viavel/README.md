# Laboratório: Do Clone ao Produto Mínimo

Este repositório apresenta o desenvolvimento e as reflexões teóricas do laboratório **"Do Clone ao Produto Mínimo"**. O projeto explora a transição da codificação manual para a arquitetura de sistemas assistida por Inteligência Artificial, focando na evolução do desenvolvedor como um estrategista técnico.

## 🧠 Reflexões sobre a Engenharia de Software Assistida por IA

### Questão A: O Novo Papel do Desenvolvedor
A maior mudança observada é que o desenvolvedor deixa de ser um mero escritor de código e passa a ser um **Arquiteto de Intenção**. Neste novo paradigma, duas competências tornam-se críticas para o sucesso profissional:

1. **Pensamento crítico sobre o output gerado:**
   A IA frequentemente "erra com confiança". O profissional que não possui a capacidade de ler, questionar e validar o código gerado torna-se apenas um "aprovador de sugestões", tornando-se facilmente substituível. Entender o *porquê* do código, mesmo sem tê-lo escrito manualmente, é o que separa o engenheiro de software de um usuário avançado.

2. **Comunicação técnica de precisão:**
   Descrever o comportamento de um sistema com clareza suficiente para que a IA produza algo funcional exige um domínio conceitual profundo. A falta de entendimento sobre arquitetura, fluxo de dados e requisitos funcionais resulta em prompts vagos e resultados inúteis. O desenvolvedor que domina essa comunicação multiplica sua produtividade; o que não domina, produz apenas retrabalho.

---

### Questão B: Ética, Engenharia Reversa e Propriedade Intelectual

1. **Onde a linha entre inspiração e plágio é cruzada?**
   A engenharia reversa transforma-se em plágio quando o produto final é funcionalmente idêntico ao original e compete no mesmo mercado, independentemente da ferramenta utilizada para gerá-lo. A intenção é o fator determinante: aprender um padrão para posteriormente criar algo próprio é legítimo e educacional; usar a IA apenas para eliminar o esforço criativo e entregar uma cópia com outro nome não é.

2. **Diretriz Ética Proposta: Princípio da "Contribuição Verificável"**
   Como padrão ético para o uso de IA, proponho o princípio da **"contribuição verificável"**: qualquer produto derivado de inspiração direta deve documentar explicitamente o que há de novo — sejam funcionalidades originais, decisões de design próprias ou soluções para problemas que a referência não resolvia. 

   Essa abordagem funciona como uma "citação acadêmica" aplicada ao software: é permitido inspirar-se em soluções existentes, mas é obrigatório provar que houve adição de valor real. Isso protege a inovação sem criminalizar o aprendizado por imitação, que sempre foi uma parte essencial de qualquer ofício criativo.
